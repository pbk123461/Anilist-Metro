# anilist metro

anilist metro is a vanilla html/css/js web app styled in a windows phone 7 / zune metro look.

## quick start

1. clone the repository.
2. open `/home/runner/work/Anilist-Metro/Anilist-Metro/index.html` in a browser.

optional: run a local static server from the repo root:

```bash
python3 -m http.server 8080
```

then open `http://localhost:8080/index.html`.

## project notes

- main application file: `index.html`
- no build step or package manager is required
- api used: `https://graphql.anilist.co`
